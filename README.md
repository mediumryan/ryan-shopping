기존 React.js 코드를 Next.js + TypeScript 코드로 변경하였습니다.
추가로 약간의 디자인 변경이 있습니다.

Supabase를 사용해 로그인 기능을 구현하였습니다.

middleware 기능을 사용하여, 사용자가 로그인을 하지 않는다면 서비스를 이용하지 못하도록 설정하였습니다.

해당 앱은 macbook air m2 기준의 화면과 galaxy s20 ultra 기준의 화면을 기준으로 작성되었습니다.

해당 앱은 여러 개인 EC몰의 이미지 및 상품명, 가격등을 참고했으며 이를 금전적인 이득을 위해 이용하지 않을 것을 밝힙니다.
또한, 저작권자의 요청이 있을 경우 관련 데이터 사용을 파기할 예정입니다.

주요 기능

- 로그인, 로그아웃, 회원가입, 비밀번호 찾기
- 상품 장바구니에 등록
- 상품 즐겨찾기에 등록
- 즐겨찾기 상품 장바구니로 옮기기
- 장바구니 내 상품 집계 (결제기능 없음)
